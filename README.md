# Katalog zasobów

## Uruchomienie
python main.py

## Funkcje
- Wyświetlanie domyślnej i spersonalizowanej kolekcji przedmiotów
- Wyświetlanie przedmiotów z kolekcji o podanej dacie, nazwie lub tagu
- Wyświetlanie wszystkich możliwych tagów
- Tworzenie własnej spersonalizowanej kolekcji
- Demonstracja między kopią a referencją listy
